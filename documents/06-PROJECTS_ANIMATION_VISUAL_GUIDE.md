## 🔧 技术实现细节

### 1. 数据结构

```typescript
// ProjectsSection.tsx 中的状态
const [hoveredProjectId, setHoveredProjectId] = useState<string | null>(null);

// 传递给 ProjectCard 的 props
{
  hoveredId: string | null,           // 当前悬停项目 ID
  onHoverChange: (id: string | null)  // 状态更新回调
}

// ProjectCard 中的计算
const isHovered = hoveredId === project.id;           // 是否当前项目被悬停
const isOtherHovered = hoveredId !== null && 
                       hoveredId !== project.id;      // 是否其他项目被悬停
```

### 2. 动画配置

```typescript
// 浮起配置
animate={{ y: isHovered ? -8 : 0 }}
transition={{ duration: 0.3, ease: "easeOut" }}

// 边框流动配置
animate={isHovered ? { x: [0, 8, 0] } : { x: 0 }}
transition={{
  duration: 0.6,
  ease: [0.34, 1.56, 0.64, 1],  // 快速启动，逐渐减速的贝塞尔曲线
  repeat: Infinity,
  repeatType: "loop",
}}

// 褪色配置
animate={{ opacity: isOtherHovered ? 0.4 : 1 }}
transition={{ duration: 0.3, ease: "easeOut" }}

// 标题变色配置
animate={{
  color: isHovered ? "hsl(var(--primary))" : "hsl(var(--card-foreground))"
}}
transition={{ duration: 0.3 }}
```

### 3. CSS 边框条纹

```css
/* 创建 8px 周期的黑白条纹 */
background: repeating-linear-gradient(
  90deg,
  #000 0px,
  #000 2px,        /* 2px 黑 */
  #fff 2px,
  #fff 4px         /* 2px 白 */
  /* 循环周期: 4px (实际上会以 8px 为最小单位) */
);
background-size: 8px 100%;  /* 8px 是一个完整周期 */

/* 通过改变 x 位置实现流动 */
transform: translateX(8px);  /* 移动一个周期 */
```

## 💡 设计原理

### 为什么使用这些动画?

1. **浮起** - 常见的 UI 反馈，表示卡片被选中
2. **边框流动** - 独特的视觉效果，吸引注意力
3. **褪色** - 强调当前卡片，减少视觉混乱
4. **标题变色** - 增强交互反馈感

### 缓动曲线的选择

```
cubic-bezier(0.34, 1.56, 0.64, 1) 意义:
│
1.5├─────●
   │    /│\
1.0├───/  \──●
   │  /    \ \
0.5├─/      \─\
   │/        \ \
0.0└─────────────●
   0   0.5   1  时间
```

- 快速上升到峰值 (y=1.56) - 过冲效果，看起来更动感
- 然后回落到目标 - 产生减速效果
- 最终稳定在 1.0 - 完成动画

这就是为什么边框条纹看起来"开始快，慢慢减速"

## 🎨 配色方案

- **边框颜色**: 黑 (#000) + 白 (#fff)
- **标题颜色变化**: 
  - 默认: var(--card-foreground) (可能是灰色或深灰)
  - 悬停: var(--primary) (品牌主色)
- **其他卡片**: 40% 不透明度 (保留轮廓但明显褪色)

## 📱 响应式考虑

- 所有动画在移动设备上 **不会触发** (无 hover)
- 触摸设备需要单独实现触摸事件处理
- 动画参数在所有分辨率上一致

## ⚡ 性能优化

✅ **已优化**:
- 使用 `transform: translateY()` 实现浮起 (GPU 加速)
- 使用 `opacity` 实现褪色 (高效)
- `pointer-events-none` 禁用边框容器的鼠标事件
- 条纹使用纯 CSS 渐变 (无图片)

## 🎯 微调指南

如果动画不符合你的期望:

| 想要的效果 | 修改项 | 调整方向 |
|-----------|--------|---------|
| 浮起更高 | `y: -8` | 改为 `-12`, `-16` 等 |
| 褪色更明显 | `opacity: 0.4` | 改为 `0.2`, `0.3` |
| 边框流动更快 | `duration: 0.6` | 改为 `0.4`, `0.5` |
| 动画更缓慢 | 各 `duration` | 都增加 50% |
| 减速效果不明显 | `ease: [...]` | 使用 `"easeInOut"` |

## 📞 常见问题

**Q: 边框在移动设备上显示吗?**  
A: 不显示。边框流动需要 hover 事件，移动设备无法触发。

**Q: 可以自定义边框颜色吗?**  
A: 可以。修改 `background: repeating-linear-gradient(90deg, #000, #fff...)` 中的颜色值。

**Q: 可以禁用某个动画吗?**  
A: 可以。注释掉对应的 `<motion.div>` 块或设置 `animate={{ condition ? {...} : {} }}`。
